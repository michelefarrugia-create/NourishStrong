# NourishStrong

NourishStrong is a React-based nutrition and mood tracking application with coaching support features.

## Features
- Meal photo upload with descriptions, hunger rating, and satisfaction.
- Mood tracking with journaling.
- Barcode scanner integrated with nutrition APIs.
- Role-based access for clients and coaches.
- User profiles with pictures.
- Support dashboard for coaching insights.

## Running Locally

1. Clone the repo
2. Run `npm install`
3. Run `npm start` to launch development server

## Deployment

Deployed on GitHub Pages via the `gh-pages` branch.
